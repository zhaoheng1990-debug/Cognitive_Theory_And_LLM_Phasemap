# Zenodo v1.2.0 release record

The repository is synchronized with two paired Zenodo v1.2.0 archives:

* `transformer_computation_source_data_v1_2_0.zip`
* `transformer_computation_code_v1_2_0.zip`

They update the stable Source Data concept DOI
https://doi.org/10.5281/zenodo.21317355 and Code concept DOI
https://doi.org/10.5281/zenodo.21317440. The archive-specific DOI is assigned
by Zenodo only when the new version is published. It must be inserted into the
Article's data and code availability statement before external submission.

The Source Data package is CC BY 4.0; the Code package is MIT. Each package
contains a file-level SHA-256 manifest. The portable Code verifier recomputes
20 reported endpoints from the paired processed Source Data and is not a claim
to ship model weights or raw hidden-state arrays.
