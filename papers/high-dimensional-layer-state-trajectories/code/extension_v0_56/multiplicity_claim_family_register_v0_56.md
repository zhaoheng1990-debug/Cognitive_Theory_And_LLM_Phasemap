# Claim-family and multiplicity register

The analyses in this study do not share a single valid statistical unit or a common null distribution. Geometry uses checkpoint-level endpoint-preserving layer permutations; coordinate audits use grouped out-of-fold prediction and graph-level sign flips; actuator tests use prompt-level paired crossings and action or direction reassignment; training controls use factorial swaps. A study-wide Benjamini-Hochberg correction across those quantities would not answer a coherent inferential question. We therefore register correction within each declared family and make no claim of a single study-wide significance level.

## v0.56 closures

Nine planned checkpoint-by-contrast tests were corrected together: `DeltaU_pre`, complete prefix and cutoff hidden state, each compared with matched recent logit margins in Qwen, Llama and Gemma. The adjusted values were 1.0, 1.0 and 1.0 for `DeltaU_pre`; `1.50e-5` for each complete-prefix and cutoff-hidden contrast. The compound gate for a distinct ordered-readback contribution failed in all checkpoints because `DeltaU_pre` was not positive. This is a limiting result, not a basis for new feature search.

### Direction-null family

Their BH-adjusted values were 0.1373, 0.1373 and 0.0588, respectively. Thus Gemma's unadjusted result is recorded as nominal only; none supports the declared cross-checkpoint direction-specificity conclusion.

## Interpretation rule

Multiplicity adjustments apply only to the explicitly named hypothesis family. They do not turn background descriptions, construction checks or negative boundaries into confirmatory outcomes. All output counts, effect sizes, confidence intervals, null specifications and pass/fail criteria remain available in the corresponding Source Data and verifier receipt.
