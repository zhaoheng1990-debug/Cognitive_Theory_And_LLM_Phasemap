# Frozen protocol: prospective confirmation of exploratory functional windows

Protocol version: v0.1  
Frozen: 18 July 2026, before extraction or inspection of confirmation outcomes

## Question

Do the model-specific windows selected in the original non-nested scan retain their stated topology, prompt-condition-class and downstream-coupling roles on graph groups that did not enter window selection?

This experiment tests recurrence within the same controlled relation-graph task family. It is not a test of universal phases, shared cross-checkpoint coordinates or task-general dynamics.

## Frozen discovery objects

The discovery set is the original 36-graph, 12-condition panel in `cm4d_prompt_dataset.csv`. The selected overall windows and readback-neighbourhood sizes are taken without modification from `cm4d_model_summary.csv`:

| Checkpoint | Frozen layers | Frozen K |
|---|---:|---:|
| Qwen | 5-6 | 500 |
| Llama | 0-2 | 500 |
| Gemma | 1-6 | 100 |

The decision windows remain Qwen 19-25, Llama 11-14 and Gemma 18-23, exactly as generated by the original 70-92% depth rule.

## Untouched confirmation objects

The confirmation set contains 24 new graph groups and the same twelve perturbation conditions. No confirmation graph entered the discovery scan. Relative to discovery, confirmation changes all three graph-level lexical factors:

- six new entity triples;
- four new relation-phrase pairs;
- twelve disjoint candidate labels drawn from the previously audited common one-token vocabulary.

The condition templates and class collapse remain fixed. For the classifier, stable and stable-shift are collapsed to stable; competition and closure remain separate. The clean row supplies each graph's within-group reference and is excluded from mechanism-class evaluation, as in the discovery analysis.

## Information boundary

All fitted objects use discovery rows only:

1. The decision-profile PCA basis and orientation are fitted on discovery clean-relative margins and applied to confirmation rows.
2. Standardization, multinomial logistic regression and ridge regression are fitted on discovery features and labels only.
3. Confirmation labels are used only for final scoring and resampling intervals.
4. No window, K value, threshold or model is selected from confirmation outcomes.

The full original window pool is evaluated on confirmation data only to calculate the prospective rank of the already frozen window. No newly high-ranking window will replace the frozen one in the manuscript.

## Endpoints

For every candidate window and K, the six original readback-neighbourhood features are computed. The frozen-window endpoints are:

1. **Topology separation:** within each confirmation graph, mean composite distance for structure-changing conditions minus mean distance for relation-preserving conditions.
2. **Prompt-condition-class information:** discovery-trained three-class macro F1 on non-clean confirmation rows.
3. **Downstream coupling:** Pearson correlation between discovery-trained ridge predictions and confirmation \(\Delta U\), where the PCA axis is fitted on discovery only.
4. **Frozen-window rank:** percentile rank of the original overall window and K under the unchanged composite score

\[
S=0.5S_{\mathrm{topology}}+0.8\max(S_{\mathrm{class}},0)+0.8\max(S_{\mathrm{downstream}},0).
\]

Here \(S_{\mathrm{topology}}=1-\overline d_{\mathrm{preserve}}\), \(S_{\mathrm{class}}\) is confirmation macro F1 and \(S_{\mathrm{downstream}}\) is confirmation Pearson correlation.

## Nulls and uncertainty

- Two thousand confirmation-graph bootstraps give 95% intervals for topology separation, macro F1 and downstream correlation.
- Nine hundred and ninety-nine discovery-label permutations give the class-information null for the frozen window.
- Nine hundred and ninety-nine within-discovery-graph permutations of \(\Delta U\) give the downstream-coupling null for the frozen window.
- Empirical one-sided values use \((1+\#\{T_{null}\geq T_{obs}\})/(1+N_{null})\).

## Frozen interpretation gates

Per checkpoint, **role recurrence** requires all of:

1. topology-separation bootstrap lower bound greater than zero;
2. macro F1 at least 0.55 and greater than the 95th percentile of its label-permutation null;
3. downstream correlation greater than zero and greater than the 95th percentile of its target-permutation null.

**Window-location recurrence** requires the frozen window/K combination to rank in the top quartile of the unchanged candidate pool.

Three-checkpoint confirmation requires role recurrence in all three checkpoints. A two-of-three outcome is reported as partial recurrence. Any other outcome is a failed confirmation. Window-location recurrence is reported separately and cannot rescue a failed role endpoint.

## Claim boundary

A positive result can upgrade the original statement from a wholly non-nested estimate to prospectively replicated functional recurrence on new graph instantiations within the same task family. It cannot establish a universal layer phase, strict coordinate homology, direct-hidden-state superiority, task-general \(\Delta U\), exact geodesics or a predictive dynamical law.

A negative or mixed result leaves the original scan exploratory and is retained as such.
