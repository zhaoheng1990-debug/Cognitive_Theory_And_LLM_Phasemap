# v0.55 Source Data extension

This incremental directory preserves the processed evidence for the frozen mixed-arithmetic actuator-transfer audit.

- `mixed_arithmetic_actuator_transfer/`: prompt-level baseline/intervention pairs, primary and null actions, replay checks, summaries, decision and frozen protocol.
- `figure_source_data/`: the four sanitized panel tables for Extended Data Fig. 9.

`manifest.csv` records size and SHA-256 for every file in this extension. Large hidden-state arrays, logits and model weights are regenerable derivatives and are not redistributed.
