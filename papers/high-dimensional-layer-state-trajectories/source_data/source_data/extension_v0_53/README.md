# Source Data extension v0.53

This directory contains the processed, row-level evidence for the falsification-first architecture, execution, metric, training and control audits added in preprint v0.53.

| Directory | Evidence |
|---|---|
| `architecture_continuity/` | 18 architecture-task-seed random fixed-map continuity conditions and matched nulls |
| `execution_order/` | Native, reversed and fixed-permutation Qwen output and geometry diagnostics |
| `incremental_path_history/`, `mixed_arithmetic_replication/` | Current-state versus ordered-prefix held-out comparisons |
| `llama_residual_coordinates/`, `llama_radial_scale/`, `llama_radial_exponent/` | Direction, norm and radial-dose metric controls |
| `pythia_component_compatibility/` | Complete E/B/N/W factorial outcomes and interaction estimates |
| `pythia_training_coordinates/` | Model-native and fixed-final coordinate audits across training |
| `actuator_coordinate_margin/` | Held-out displacement, margin and matched-null control-chain evidence |
| `figure_source_data/` | Exact plotted inputs for Extended Data Figs. 13 and 14 |

`claim_boundary_ledger.csv` is the public claim-evidence map. `release_verification.json` records the frozen audit status. Prompt IDs are descriptive and workstation paths are removed. Model weights and large hidden-state derivatives are not redistributed.
