# Source Data extension v0.52

This archive contains the row-level and plotted evidence for the three experimental closures in preprint v0.52.

| Directory | Evidence |
|---|---|
| `task_generalization/` | Controlled lexical and addition tasks plus a deterministic 96-item, four-choice ARC-Challenge audit |
| `predictive_forecasting/` | Graph-held-out final candidate-margin forecasts, bootstrap intervals and 50 order-null refits |
| `random_initialization_geometry/` | Trained checkpoints and three random initializations for each architecture |
| `output_boundary_control/` | Train/test splits, actions, full-vocabulary top-1 rows and classifier audits for Qwen, Llama and Gemma |
| `safety_matched_reassignment/` | Fifty gate-, condition- and action-multiset-matched reassignments per checkpoint |
| `summary_tables/` | Manuscript-facing closure summaries and machine-readable verdict |
| `figure_source_data/` | Source tables for all current main and extended figures |

Large hidden-state arrays and model weights are not redistributed. They are regenerable derivative intermediates of third-party checkpoints. The archive supports direct numerical audit without requiring those arrays.

The evidence supports cross-task recurrence of layer-order geometry, a bounded held-out candidate-margin forecast, an architecture-compatible random-state scaffold and cross-checkpoint reachability of a declared emitted-token candidate boundary. It does not support a task-general scalar coordinate, an autonomous state equation, answer-correctness control, deployment safety or fine-grained trajectory-specific dosing.
