# V1R4 Source Data release

The canonical V1R4 package is at `source_data/v1r4_final/`. It contains
authoritative tables, figure-level derivatives and data-provenance records.

Run `../../code/release_v0_60/run_v1r4_reproduction.ps1` from the paper
directory to recompute the 20 reported endpoints. The contents are released
under CC BY 4.0; see the package-level licence. Raw hidden-state arrays and
model weights are excluded because they are third-party derivatives or cannot
be redistributed.
