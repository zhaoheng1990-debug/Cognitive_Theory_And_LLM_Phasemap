## What v0.55 adds

The frozen mixed-arithmetic assay tests whether the relation-graph actuator procedure transfers after training-only refitting while layer windows, action library, regularization, classifier settings and gate thresholds remain fixed.

- Pooled strict crossings: 2/45 eligible correction prompts.
- Non-target top-1 changes: 1/240 stable or competition prompts.
- Pooled specificity exceeds the address-null 95th percentile; plus-one one-sided empirical P = 1/51.
- Only Qwen passes the powered positive-direction gate. Llama crosses once but has negative median displacement; Gemma is underpowered with four eligible prompts.
- The predeclared two-checkpoint confirmation gate therefore fails.

The supported result is partial protocol-level transfer, not confirmed cross-task output control. Confirmatory emitted-token control remains bounded to the relation-graph task family described in the manuscript.

## Boundaries and availability

The evidence supports an observable ordered process and bounded control of a declared candidate boundary. It does not establish an exact geodesic, least action, universal state equation, answer-correctness improvement, open-ended generation control or deployment safety. Vocabulary readbacks remain diagnostics.
