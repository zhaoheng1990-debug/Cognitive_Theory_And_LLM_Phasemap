# arXiv TeX package v0.37

Compile `main.tex` with pdfLaTeX. The package uses TeX Live fonts and standard packages for arXiv compatibility. It contains the full expanded preprint: 15 main figures, 13 supplementary figures, Methods, declarations and discovery chronology. The archive DOI must be finalized before upload.

The standard Abstract is in `abstract_source.tex` and is embedded in `main.tex` using the LaTeX `abstract` environment.
