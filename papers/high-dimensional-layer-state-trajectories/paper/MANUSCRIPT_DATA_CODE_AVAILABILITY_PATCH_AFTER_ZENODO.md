## Data availability

Processed panel- and row-level tables are archived in the V1R4 Source Data
release at [SOURCE_DATA_V1_2_0_DOI] and under the stable concept DOI
https://doi.org/10.5281/zenodo.21317355. They are mirrored in the public
repository branch at https://github.com/zhaoheng1990-debug/Cognitive_Theory_And_LLM_Phasemap/tree/high-dimensional-layer-state-trajectories. The archive includes prompt and checkpoint metadata, random seeds, split records, null specifications, figure contracts and file-level checksums. Raw hidden-state arrays are large derivatives of third-party checkpoints and are not redistributed; documented prompts, checkpoint revisions and extraction scripts permit regeneration subject to checkpoint access, storage and licence constraints. Model weights are not redistributed.

## Code availability

Analysis scripts, deterministic figure scripts, environment records and
portable endpoint verifiers are archived in the V1R4 Code release at
[CODE_V1_2_0_DOI] and under the stable concept DOI
https://doi.org/10.5281/zenodo.21317440. The public repository mirrors the
current release. The default verifier recomputes reported endpoints from
processed Source Data; full model reruns require the listed checkpoints and
upstream datasets that cannot be redistributed.
