# arXiv TeX package v0.52

Compile `main.tex` with pdfLaTeX. This version extends v0.50 with controlled lexical and addition tasks, a four-choice ARC audit, held-out final-margin forecasting, three random initializations per architecture, cross-checkpoint output-boundary control and safety-matched reassignment nulls. It contains 17 main figures and 13 supplementary figures. Model weights and large hidden-state arrays are not redistributed.
