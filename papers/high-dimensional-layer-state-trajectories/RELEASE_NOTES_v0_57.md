# Reproducibility release v0.57

Date: 2026-08-06

## Scope

v0.57 is a publication-material update to the frozen v0.56 reproducibility package. It does not alter any code, processed Source Data, model metadata, verifier, result, null distribution or numerical claim.

## Added publication files

- Full Nature Article submission PDF: `paper/nature_initial_submission_v0_37.pdf`
- Article source: `paper/manuscript_v0_37_final_polish.md`
- Supplementary Methods PDF and TeX source: `paper/supplementary_methods_v0_20.pdf` and `paper/supplementary_methods_v0_20.tex`

The v0.37 editorial update verifies the clean-versus-conflict candidate notation, clarifies the inherited confidence-gate operating point and defines the gate-operator intervention. These are reporting and clarity changes; no source-data value or analytic output was recomputed or changed.

## Evidence continuity

The substantive empirical package remains v0.56. In particular, the predecision coordinate audit, empirical-subspace direction null and new-graph geometry confirmation retain their original source files and verification routes. Model weights, runtime binaries and large raw hidden-state arrays remain excluded.
