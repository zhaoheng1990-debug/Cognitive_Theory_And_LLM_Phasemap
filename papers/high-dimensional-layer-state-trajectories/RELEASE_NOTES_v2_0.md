# Reproducibility release v2.0.0

This release updates the public reproducibility route for **Architecture,
training and execution organize Transformer computation**.

## What changed

- Added a single eight-family processed-data verification entry point.
- Synchronized the public verifiers with the archived review package, including
  newline normalization for the fixed prompt-manifest digest and support for the
  shared new-graph geometry directory.
- Updated the repository documentation to cite the published v2.0.0 Zenodo
  Source Data and reproduction records.

## Verification boundary

The entry point recomputes reported numerical endpoints and declared null
calculations from processed Source Data. It does not load model weights, rerun
inference or expand the manuscript's bounded claims.
