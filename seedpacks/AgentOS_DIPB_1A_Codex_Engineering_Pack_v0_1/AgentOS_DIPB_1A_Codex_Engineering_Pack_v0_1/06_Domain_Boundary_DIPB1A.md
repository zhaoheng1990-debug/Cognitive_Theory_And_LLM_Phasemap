# Domain Boundary: DIPB-1A

## What DIPB-1A proves

DIPB-1A can prove:

```text
A governed harness can enumerate local raw domain materials,
assign stable source IDs,
compute hashes,
record metadata,
and produce provenance artifacts for PM audit.
```

## What DIPB-1A does not prove

DIPB-1A does not prove:

```text
Domain case quality
Domain case eligibility
Replay readiness
Structured input pack validity
Domain capability
Benchmark performance
Production release readiness
Human authorization
```

## Core frozen principle

```text
Candidate source inventory is not a domain capability.
Provenance capture is not case eligibility.
Harness compilation is not authority.
```

## Stage transition rule

DIPB-1B may start only after PM audits DIPB-1A return pack and confirms PASS or a safe BLOCKED remediation path.
